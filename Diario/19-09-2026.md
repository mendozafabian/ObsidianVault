**Prueba de batería (`powercfg /batteryreport`):** Para evaluar el estado de la batería, abre el Símbolo del sistema o PowerShell y ejecuta el comando `powercfg /batteryreport`. Esto genera un archivo HTML en tu carpeta de usuario. Ábrelo en un navegador y compara los valores de "Design Capacity" (capacidad de fábrica) con "Full Charge Capacity" (capacidad actual) para verificar el nivel de desgaste. Si el segundo valor es significativamente menor, la batería retendrá poca carga. El resultado deseable es que el valor de "Full Charge Capacity" sea idéntico o muy cercano al de "Design Capacity". Para un equipo de segunda mano, mantener un 80% o más de su capacidad original es un atributo óptimo.

**Verificación de especificaciones (`dxdiag`):** Para comprobar la integridad de la memoria RAM, presiona Windows + R, escribe `mdsched.exe` y ejecuta la Herramienta de diagnóstico de memoria de Windows. Selecciona la opción para reiniciar el equipo inmediatamente y buscar problemas. Al finalizar el proceso, el sistema se reiniciará; puedes verificar el resultado abriendo el "Visor de eventos", navegando a Registros de Windows > Sistema, y buscando el evento "MemoryDiagnostics-Results" para confirmar que no hay sectores de memoria defectuosos. En la herramienta de diagnóstico, revisa la pestaña "Sistema" para verificar el modelo del procesador y la cantidad real de RAM. En la pestaña "Pantalla", confirma el modelo exacto de la tarjeta gráfica y sus controladores. El atributo esperado es que la información del modelo del procesador, la cantidad de memoria RAM y el modelo de la tarjeta gráfica coincida con precisión con las características anunciadas por el vendedor.

**Estado del disco (`wmic diskdrive get status`):** Para revisar el estado básico de la unidad de almacenamiento, abre el Símbolo del sistema y ejecuta `wmic diskdrive get status`. La consola debe devolver el estado "OK" para cada unidad física instalada. Si la respuesta contiene "Pred Fail" o cualquier otro error, el disco duro o SSD tiene fallas inminentes en su sistema SMART. El único atributo aceptable es que la consola devuelva el texto "OK" para cada unidad de almacenamiento. Cualquier otra respuesta es indicador de una falla inminente del disco.

**Prueba de pantalla (colores RGB):** Para probar el estado del panel de la pantalla, abre un navegador web, busca una prueba de pantalla RGB en pantalla completa y alterna entre imágenes completamente blancas, negras, rojas, verdes y azules. Inspecciona el panel visualmente con detenimiento para detectar píxeles muertos (puntos que no encienden), píxeles atascados (puntos que se quedan en un solo color) o fugas de luz severas en los bordes. El resultado deseable es visualizar iluminación y tonos completamente uniformes, confirmando la ausencia de píxeles muertos (puntos negros apagados), píxeles atascados (puntos fijos en un color) y fugas de luz en los márgenes.

**Prueba de periféricos y puertos:** Para verificar el hardware periférico y de entrada, abre la aplicación "Cámara" del sistema para comprobar la captura de video y la aplicación "Grabadora de sonido" para confirmar que el micrófono interno capta audio sin interferencias. Abre el "Bloc de notas" y presiona cada tecla individualmente para asegurar que ninguna se atasque, omita caracteres o registre pulsaciones dobles. Finalmente, conecta dispositivos (como auriculares, memorias USB y el cargador) en cada puerto disponible para confirmar que la placa base los reconoce correctamente y suministra energía. Los atributos óptimos incluyen una imagen de cámara sin distorsión, grabación de audio sin estática, un teclado donde cada tecla registra exactamente una pulsación sin esfuerzo adicional, y puertos que reconocen memorias USB o suministran energía de manera inmediata.

**Diagnóstico de memoria RAM (`mdsched.exe`):** Windows + R, escribe `mdsched.exe` y ejecuta la Herramienta de diagnóstico de memoria de Windows. Selecciona la opción para reiniciar el equipo inmediatamente y buscar problemas. El resultado deseable al consultar el Visor de eventos es la indicación explícita de que no se encontraron errores. Esto garantiza que la memoria no causará cierres inesperados ni pantallas azules.
